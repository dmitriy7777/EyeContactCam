# EyeContact Cam

Windows desktop-приложение для локальной коррекции направления взгляда. Приложение захватывает веб-камеру, выполняет трёхсекундную калибровку и перерисовывает каждый глаз моделью DeepWarp ONNX. Обработанное изображение передаётся в OBS Virtual Camera через чистое окно вывода.

## Запуск

```powershell
dotnet run --project C:\Projects\EyeContactCam\EyeContactCam.csproj
```

1. Нажмите **Запустить камеру**.
2. Нажмите **Сканировать** и 3 секунды смотрите прямо в объектив.
3. Убедитесь, что включена **Сильная коррекция взгляда**. Эффект должен быть виден уже в главном окне — OBS на качество эффекта не влияет.

## Одноразовое подключение OBS

1. Установите OBS Studio с https://obsproject.com/download и запустите его.
2. Нажмите `+` в панели **Источники** → **Захват окна**.
3. Назовите источник `EyeContactCam`.
4. В поле **Окно** выберите `[EyeContactCam] EyeContact Cam Output`.
5. Обрежьте источник по размеру холста: правый клик → **Трансформировать** → **Вписать в экран**.
6. Нажмите **Запустить виртуальную камеру** в OBS.
7. В Google Meet откройте **Настройки → Видео → Камера** и выберите `OBS Virtual Camera`.

При следующих запусках источник уже сохранён в OBS. Достаточно запустить EyeContactCam, нажать **Активировать виртуальную камеру**, а затем выбрать `OBS Virtual Camera` в Meet.

Профиль хранится в `%LOCALAPPDATA%\EyeContactCam\profile.json`. Видео и изображения никуда не отправляются.

## Нейросетевой движок

- Используются две локальные ONNX-модели, отдельно для левого и правого глаза. Вход модели: глаз 64×48, шесть ориентиров века и вычисленный угол перенаправления.
- Выполнение идёт через Microsoft ONNX Runtime на CPU; интернет во время работы не нужен.
- На старом процессоре частота кадров может быть ниже 30 FPS.
- Сильный поворот головы или полностью закрытый глаз всё ещё не могут быть восстановлены достоверно.
- На Windows 10 создание системной виртуальной камеры через `MFCreateVirtualCamera` недоступно, поэтому используется OBS.
