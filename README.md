# EyeContact Cam

Windows desktop MVP для локальной коррекции направления взгляда. Приложение захватывает веб-камеру, выполняет трёхсекундную калибровку лица/глаз, мягко сдвигает содержимое областей глаз к объективу и отдаёт чистое окно в OBS Virtual Camera.

## Запуск

```powershell
dotnet run --project C:\Projects\EyeContactCam\EyeContactCam.csproj
```

1. Нажмите **Запустить камеру**.
2. Нажмите **Сканировать** и 3 секунды смотрите прямо в объектив.
3. Установите OBS Studio, если приложение предложит это сделать.
4. Нажмите **Активировать виртуальную камеру**.
5. Только при первом запуске в OBS добавьте `Захват окна` и выберите `[EyeContactCam] EyeContact Cam Output`.
6. В Google Meet выберите `OBS Virtual Camera`.

Профиль хранится в `%LOCALAPPDATA%\EyeContactCam\profile.json`. Видео и изображения никуда не отправляются.

## Ограничения MVP

- Это геометрическая коррекция глаз, а не генеративная нейросетевая реконструкция; небольшой взгляд в сторону исправляется лучше сильного поворота головы.
- На Windows 10 создание системной виртуальной камеры через `MFCreateVirtualCamera` недоступно, поэтому используется OBS.
- Перед релизом нужны тесты на конкретной камере, разрешении и освещении.
