# EyeContactCam — агентский контекст

## Цель проекта

Windows desktop-приложение на .NET/WPF, которое:

- получает видео со встроенной камеры ноутбука;
- калибрует прямой взгляд пользователя в объектив;
- корректирует положение радужек, когда пользователь читает с экрана;
- показывает обработанный результат в основном окне;
- выводит чистое видео в отдельное окно `EyeContact Cam Output`;
- использует OBS Virtual Camera, чтобы результат можно было выбрать в Google Meet.

OBS не создаёт эффект. Эффект обязан быть виден в основном окне EyeContactCam. OBS только публикует уже обработанное окно как виртуальное устройство камеры.

## Текущий путь

Проект был перенесён пользователем сюда:

`C:\Projects\ForCamera\EyeContactCam`

Готовая сборка:

`C:\Projects\ForCamera\EyeContactCam\publish\EyeContactCam.exe`

Не использовать старый путь `C:\Projects\EyeContactCam`.

## Стек

- .NET 8 WPF
- OpenCvSharp 4.10
- OpenCV Haar Cascades для лица и глаз
- Microsoft ONNX Runtime и две DeepWarp ONNX-модели для перерисовки глаз
- OBS Studio / OBS Virtual Camera для публикации обработанного изображения

Основные файлы:

- `MainWindow.xaml` — интерфейс.
- `MainWindow.xaml.cs` — цикл камеры, сканирование и обновление UI.
- `CameraPipeline.cs` — обнаружение лица/глаз/зрачков и вычисление целевого смещения.
- `NeuralGazeCorrector.cs` — CPU inference DeepWarp и смешивание результата с кадром.
- `OutputWindow.xaml` — чистое окно для захвата OBS.
- `ObsVirtualCamera.cs` — обнаружение и запуск OBS.
- `Assets/*.xml` — Haar-модели OpenCV.

## Что уже реализовано

- Захват камеры через DirectShow, 1280×720, целевые 30 FPS.
- Зеркальное отображение кадра.
- Трёхсекундный скан при прямом взгляде в объектив.
- Раздельная калибровка левого и правого глаза.
- Профиль сохраняется в `%LOCALAPPDATA%\EyeContactCam\profile.json`.
- Временное сглаживание координат глаз и зрачков.
- Нейросетевая перерисовка каждого глаза через `gaze_L.onnx` и `gaze_R.onnx`.
- Сила коррекции по умолчанию 100%.
- Диагностика в UI:
  - `Глаза найдены: N/2`;
  - величина применённого сдвига в пикселях.
- Отдельное окно для OBS.
- Release-сборка проходит с 0 errors / 0 warnings.

## Последняя проблема пользователя

Пользователь сообщает, что эффект почти или совсем не виден: глаза могут прыгать, но зрачки визуально не направляются в камеру при реальном отведении взгляда.

Последняя версия усилила перенос радужки и добавила диагностику. Следующий обязательный шаг — получить от пользователя показания строки диагностики при отведённом взгляде:

- Если `Глаза найдены: 0/2` или `1/2`, проблема в Haar-детекторе глаз. Нужно заменить детектор на устойчивые facial/iris landmarks.
- Если глаза `2/2`, но сдвиг всегда `0.0 px`, проблема в `FindPupil` или калибровочном target.
- Если сдвиг заметный (например, 5–15 px), но изображение визуально не меняется, проблема в `WarpIris` и нужно переходить к переносу/реконструкции текстуры радужки.

## Ограничения оборудования

На машине обнаружены:

- Intel HD Graphics Family, 1 ГБ;
- NVIDIA GeForce GT 750M, 2 ГБ;
- старый драйвер NVIDIA;
- `nvidia-smi` отсутствует.

NVIDIA Broadcast/современный Maxine Eye Contact на этом оборудовании не подходит. Ориентироваться на CPU.

ОС — Windows 10. Официальный `MFCreateVirtualCamera` требует Windows 11 build 22000+, поэтому используется OBS Virtual Camera.

## Ограничение текущего алгоритма

Текущий движок геометрический. Он перемещает текстуру вокруг обнаруженной радужки, но не умеет полноценно генерировать новые веки, белок и радужку при сильном отведении глаз. Более долгий скан или вращение головы во время сканирования это не исправляют. Во время калибровки пользователь должен неподвижно смотреть прямо в объектив.

Были исследованы GazeFlow, GazeCorrection, STED-gaze и другие gaze-redirection проекты. Готовой поддерживаемой ONNX-модели для прямого встраивания в Windows/.NET не найдено; большинство доступных весов требуют старых TensorFlow/PyTorch-окружений и рассчитаны на исследовательский запуск. Не заявлять наличие AI/ONNX, пока реальная модель не подключена и не протестирована.

## Сборка

```powershell
dotnet build "C:\Projects\ForCamera\EyeContactCam\EyeContactCam.csproj" -c Release
dotnet publish "C:\Projects\ForCamera\EyeContactCam\EyeContactCam.csproj" -c Release -r win-x64 --self-contained false -o "C:\Projects\ForCamera\EyeContactCam\publish"
```

Перед публикацией закрыть запущенный `EyeContactCam.exe`, иначе файлы могут быть заблокированы.

## Проверка результата

1. Запустить `publish\EyeContactCam.exe`.
2. Запустить камеру.
3. Выполнить новый скан, три секунды глядя строго в объектив.
4. Убедиться, что включена `Сильная коррекция взгляда` и сила равна 100%.
5. Посмотреть на текст выше, ниже и сбоку от камеры.
6. Записать `Глаза найдены: N/2` и величину сдвига.
7. Сначала добиться видимого результата в главном окне; OBS подключать только после этого.
